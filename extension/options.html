LeakGuard extension

This extension reads your LeakGuard data with an API token — a read-only key you create yourself. It never asks for, sees or stores your account sign-in credentials, and the token can never change, submit or delete anything.

1. Create a token

Open LeakGuard, sign in, and in the Privacy Center → API access section create a token (name it something like “browser extension”). Copy it — it is shown exactly once.

2. Paste it here

The token is kept in this browser's extension storage (chrome.storage.local) and is only ever sent to leakguard-hh8e.onrender.com as a Bearer header. Revoke it any time in the Privacy Center and this extension stops working instantly.
