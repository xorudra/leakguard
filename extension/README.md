# LeakGuard — browser extension

Your LeakGuard exposure at a glance, without opening the site: your
exposure score and band, how many exposures the latest scan found,
how many removal cases need one step from you, and the server's one
recommended next action — plus a button straight to LeakGuard.

## How it authenticates (and what it never does)

The extension uses **your own read-only API token** — and nothing
else. It never asks for, sees or stores your LeakGuard sign-in
credentials. Tokens are created by you in the LeakGuard Privacy
Center (**API access** section), are **read-only by construction**
on the server (a token can never change, submit or delete
anything), are stored server-side only as a hash, and can be
revoked there at any time — revoking stops this extension
instantly.

The token is kept in `chrome.storage.local` and is sent only to
`https://leakguard-hh8e.onrender.com` as a Bearer header. That
origin is also the extension's only host permission.

## Install (load unpacked — free)

1. Get this folder onto your computer — either clone the LeakGuard
   repo, or download `leakguard-extension.zip` (built by
   `tools/build_extension_zip.py`) and unzip it.
2. Open `chrome://extensions` in Chrome (or `edge://extensions`,
   `brave://extensions` — any Chromium browser works).
3. Switch on **Developer mode** (top right).
4. Click **Load unpacked** and select this `extension/` folder
   (the one containing `manifest.json`).
5. Click the LeakGuard toolbar icon → **Add your API token** →
   paste the token from the Privacy Center → **Test connection**.

## Why isn't this on the Chrome Web Store?

Honestly: publishing there costs a one-off developer registration
fee, and LeakGuard's rule is **free means free** — for the owner
and for users. So for now the extension is sideload-only via the
steps above. If that ever changes, this README will say so.

## Files

| File | What it does |
|---|---|
| `manifest.json` | Manifest V3; permissions are `storage` + the single LeakGuard host |
| `popup.html` / `popup.js` / `popup.css` | The toolbar popup (score, counts, next action) |
| `options.html` / `options.js` / `options.css` | Token entry + connection test |
| `shared.js` | The one API helper both pages use |
| `icons/` | Generated by `tools/build_icons.py` |

No build step, no dependencies, no tracking — the extension's only
network traffic is to the LeakGuard origin above.
